# Enum 정의 및 한글 표시값

## 결함 종류

| 서버 코드 | 한글 표시 |
|---|---|
| `CRACK` | 균열 |
| `SURFACE_DAMAGE` | 표면손상 |
| `BLOCKAGE` | 막힘 |

## 결함 등급

| 서버 코드 | 화면 등급 | 기준 |
|---|---|---|
| `CRITICAL` | 1등급(심각) | 즉시 보수 검토가 필요한 결함 |
| `WARNING` | 2등급(주의) | 보수 계획 또는 추가 점검이 필요한 결함 |
| `NORMAL` | 3등급(관찰) | 정기적인 경과 관찰이 필요한 결함 |

막힘은 `0.6` 이상 `CRITICAL`, `0.3` 이상 `WARNING`, `0.3` 미만
`NORMAL`을 권장한다. 균열과 표면손상은 측정 필드가 추가되기 전까지 AI 또는
작업자가 등급을 결정하며, `confidence`를 결함 등급으로 사용하지 않는다.

## 보수 상태

| 서버 코드 | 한글 표시 |
|---|---|
| `BEFORE` | 보수 이전 |
| `IN_PROGRESS` | 보수 중 |
| `COMPLETED` | 보수완료 |
| `ON_HOLD` | 보수 보류 |

## 점검 상태

| 서버 코드 | 한글 표시 |
|---|---|
| `READY` | 점검 전 |
| `RUNNING` | 점검 중 |
| `COMPLETED` | 점검 완료 |
| `ABORTED` | 점검 중단 |

## 점검 모드

| 서버 코드 | 한글 표시 |
|---|---|
| `AUTO` | 자동 |
| `MANUAL` | 수동 |
